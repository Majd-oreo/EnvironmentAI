# بيئتي · Be'ati — النسخة المجانية بالكامل

> **افهم أثرك البيئي، وغيّر العالم بخطوة.**

نسخة من «بيئتي» **مجانية 100%**: بدون مفتاح API، وبدون خادم، وبدون أي اشتراك.
ملفات **HTML و CSS و JavaScript** فقط، مع **قاعدة معرفة بيئية بصيغة JSON**.

## كيف تعمل؟

| الجزء | كيف يعمل |
|---|---|
| التعرّف على الصورة | نموذج **MobileNet** المجاني يعمل **داخل المتصفح نفسه** (TensorFlow.js). الصورة لا تُرسل لأي خادم. |
| المعلومات البيئية | من ملف `assets/data/knowledge.js` (محتواه JSON): ‏28 نوع مادة و55 عنصرًا شائعًا و14 سؤالًا عامًا. |
| البحث بالاسم | اكتب اسم العنصر بالعربي أو الإنجليزي (مثل: بطارية، كرتونة، زيت قلي) واحصل على تقريره فورًا. |
| المساعد «نبتة» | يجيب من قاعدة المعرفة: أين أسلّمه، أفكار لإعادة استخدامه، البدائل، الخطورة، مدة التحلل، الفرز، السماد… |

**ملاحظة صادقة:** التعرّف على الصور تقريبي. يعرف أشياء شائعة مثل العبوات والكرتون والموز والهواتف واللابتوب والملابس، وقد يخطئ في غيرها. لذلك يعرض الموقع دائمًا اقتراحات بديلة وخانة بحث لاختيار العنصر الصحيح.

## محتويات المجلد

```
beati-free/
├── index.html               الموقع كاملًا — افتحه بالنقر المزدوج مباشرة
└── assets/
    ├── data/knowledge.js    ← قاعدة المعرفة البيئية (JSON داخل ملف JavaScript، يمكنك تعديلها)
    ├── js/beati.js          كل كود الموقع في ملف واحد
    ├── css/styles.css       التصميم
    └── img/favicon.svg      الأيقونة
```

**يعمل بالنقر المزدوج على `index.html`** من جهازك مباشرة، أو بعد رفعه على أي استضافة. التعرّف على الصور يحتاج اتصالًا بالإنترنت في المرة الأولى فقط لتحميل النموذج.

## رفعه على GitHub Pages (رابط مجاني يفتح من الجوال)

1. افتح مستودعك على GitHub.
2. اضغط **Add file → Upload files**، واسحب **محتويات** مجلد `beati-free`: الملف `index.html` ومجلد `assets` كاملًا (مع مجلد `data` داخله).
3. اضغط **Commit changes**.
4. من المستودع: **Settings → Pages**، ثم تحت **Branch** اختر `main` والمجلد `/ (root)`، واضغط **Save**.
5. بعد دقيقة أو دقيقتين يظهر الرابط، مثل: `https://majd-oreo.github.io/اسم-المستودع/`

> يجب أن يكون `index.html` في أعلى المستودع وليس داخل مجلد آخر.
> أول تحليل صورة يحتاج تحميل النموذج (بضع ميغابايت) مرة واحدة، ثم يصبح أسرع.

## إضافة عنصر جديد إلى قاعدة المعرفة

افتح `assets/data/knowledge.js` بأي محرر نصوص (مثل VS Code أو Notepad)، وأضف عنصرًا داخل `"items"`، مثلًا:

```json
{ "id": "yogurt_cup", "name": "كأس لبن بلاستيكي", "name_en": "Yogurt cup", "profile": "pp",
  "summary": "كأس لبن من بلاستيك PP، قابل لإعادة الاستخدام، وتدويره يختلف حسب الجهة.",
  "materials": [{ "name": "بولي بروبيلين", "name_en": "PP (#5)", "category": "plastic", "share": "الكأس" }],
  "labels": ["cup"], "keywords": ["كاسة لبن", "لبن", "زبادي"] }
```

- `profile`: نوع المادة، ومنه تأتي باقي المعلومات تلقائيًا (التدوير، الأثر، التخلص…). الأنواع المتوفرة:
  `pet, hdpe, pp, ps_foam, plastic_film, mixed_plastic, glass, aluminium, steel, paper, cardboard, paper_soiled, beverage_carton, paper_cup, organic, battery, ewaste, lamp, textile, wood, ceramic, rubber, medicine, chemical, aerosol, cooking_oil, diaper, cigarette`
- `keywords`: كلمات البحث، أضف الأسماء العامية أيضًا.
- `labels`: أسماء إنجليزية من تصنيفات نموذج الصور (ImageNet) مثل `water bottle` و `banana` و `laptop`.
- يمكنك أيضًا وضع `reuse_ideas` أو `alternatives` أو `extra_tips` داخل العنصر لتخصيصه.

انتبه للفواصل `,` بين العناصر وللأقواس. إذا توقف الموقع عن العمل بعد التعديل، فغالبًا هناك فاصلة ناقصة أو زائدة: افتح الموقع ثم اضغط F12 وانظر إلى تبويب Console لترى السطر الذي فيه المشكلة.
